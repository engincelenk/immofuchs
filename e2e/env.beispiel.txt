# Vorlage fuer die lokalen Geheimnisse ALLER drei E2E-Teile (API-Suite,
# Browser-Suite, Dashboard) - ein Satz Passwoerter fuer alles.
#
# 1. Diese Datei kopieren und im selben Ordner als ".env.local" speichern.
# 2. Echte Werte eintragen.
# 3. ".env.local" wird von e2e\server.js, e2e\run-api-e2e.ps1 und
#    e2e\run-browser-e2e.ps1 automatisch geladen und ist ueber .gitignore von
#    Git ausgeschlossen - landet also nie im Repo.
#
# ACHTUNG - haeufigste Fehlerquelle (19.08. zweimal passiert): auf die
# GENAUEN Schluesselnamen achten. E2E_PASSWORD_ADMIN ist das PASSWORT des
# Admin-Kontos; E2E_SESSION_ADMIN ist etwas voellig anderes (eine
# Session-UUID) und wird bei einem Passwort-Wert stillschweigend ignoriert -
# die 23 Admin-Tests ueberspringen sich dann kommentarlos selbst.
# Zur Kontrolle: powershell -File e2e\diagnose-env.ps1
#
# Hinweis: die Vorlage heisst bewusst "env.beispiel.txt" und nicht
# ".env.local.example" - Dateien, die mit einem Punkt beginnen oder ".env" im
# Namen tragen, lassen sich ueber den Geraete-Uebertragungsweg nicht anlegen.
